# IPTV Studio Premium (v1.0.0)

Applicazione Android / Android TV basata su Kivy e Buildozer (`org.iptvstudio.iptvstudiopremium`) per la gestione di flussi/playlist con riproduzione tramite VLC (`org.videolan.vlc`) o player integrato.

## Installazione via ADB
adb connect <IP_TV_BOX>:5555
adb install -r iptvstudiopremium-1.0.0-arm64-v8a_armeabi-v7a-debug.apk
